# 📱 PhonePe Transaction Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **PhonePe Transaction Analytics Dashboard** built using **Microsoft Power BI** to analyze digital payment transactions, user behavior, transaction trends, and payment performance.

The dashboard is developed using two datasets — `All_Transactions` and `All_Users` — containing **300,000 transaction records** and **100,000+ user records**. A dedicated Date Table and custom DAX measures were created to enhance time-based analysis and KPI calculations.

The dashboard provides an overview of transaction performance, user demographics, payment services, transaction trends, and usage patterns through interactive visualizations.

## 📂 Dataset

The project uses two datasets:

- **All_Transactions:** Contains 300,000 records related to transaction activity, transaction values, payment services, and transaction details.
- **All_Users:** Contains 100,000+ records related to user information and user segmentation.

Additional data modeling components:

- **Date Table:** Created to enable time-based analysis and proper month-wise reporting.
- **Measures:** Custom DAX measures created for KPIs, calculations, and analytical insights.

## 📊 Dashboard Features

### 🔹 Key Performance Indicators (KPIs)
- **Total Transactions:** 300K
- **Total Transaction Value:** ₹3.47 Billion
- **Unique Users:** 108K
- **Successful Transaction Rate:** 96%
- **Transaction Growth (MoM):** 8.97%
- **Transaction Value Growth (MoM):** 8.98%

### 🔹 Visualizations & Analysis

- **Monthly Transaction Analysis:** Trend analysis of total transactions and transaction value throughout the year.
- **Age Segment Contribution:** Analysis of user contribution across different age segments.
- **Service Transaction Value Analysis:** Breakdown of transaction values across Loans, Insurance, Money Transfer, and Recharge Bills.
- **Top 5 Users:** Identification of the top users based on transaction value.
- **Weekday vs Weekend Analysis:** Comparison of transaction activity between weekdays and weekends.
- **Payment Status Analysis:** Overview of Failed, Pending, and Successful payment statuses.
- **Insights Panel:** Highlights important trends and observations from transaction data.

## 📈 Data Modeling & DAX

The project includes:
- Tansform of tables
- Creation of a dedicated Date Table.
- Data modeling using relationships between datasets.
- Custom DAX measures for transaction counts, transaction value, unique users, successful transaction rate, and month-over-month growth.
- Time-based analysis using the Date Table.
- Interactive filters and slicers for months and payment statuses.

- The successful transaction rate is approximately **96%**.
- Weekdays contribute a larger share of transaction activity than weekends in the displayed analysis.
- Loans contribute the highest transaction value among the service categories shown.

- Month-over-month metrics help track changes in transaction volume and transaction value.

The objective of this project is to transform raw digital payment data into meaningful business insights using Power BI. It demonstrates data cleaning, data modeling, DAX measure creation, time-based analysis, KPI reporting, and interactive dashboard design.
